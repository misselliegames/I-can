# I can

Детская игра-комикс про Superboy Ivan, бегемотика Bongo, Madam Boo и Simon the Spider. Уровень английского — Pre-A1.

Основные рабочие файлы находятся прямо в этой папке: `index.html`, `app.js`, остальные JS/CSS, `display/` и `assets/story/`. Это самостоятельный статический сайт. Публикация: GitHub Pages, репозиторий `misselliegames/I-can`, ветка `main`, папка `/`.

## Локальный запуск

Можно открыть `index.html` в браузере. Для проверки через HTTP: `npm run preview`, затем `http://127.0.0.1:5174/`. Сервер запускается встроенным Node.js, без установки зависимостей.

Для автоматической проверки один раз выполнить `npm install`, затем `npm run check`. Зависимости нужны только для разработки и тестов; на сервер устанавливать ничего не нужно. При наличии Chrome вместо Edge: переменная окружения `BROWSER=chrome`. Для проверки сайта: `BASE_URL=https://misselliegames.github.io/I-can/`.

## Материалы и резервные копии

`archive/` — локальный архив прежней игры, первоначальных рисунков, промптов, старых вариантов и проверок. Архив исключён из Git и не отправляется на сайт. Старые абсолютные пути в архивных JSON описывают историю; использовать их как текущую конфигурацию не следует. Рабочая версия — файлы в корне I-can.

`ASSET-MANIFEST.json` перечисляет 58 используемых ресурсов, включая 45 изображений WebP, с размерами и SHA256. Активные файлы занимают около 7 МиБ вместо 87 МиБ PNG-версии. Сохранены размеры иллюстраций; качество WebP — 92. Исходные PNG остаются в архиве.

Последние исправления установлены: сидящий Иван с бутербродом, футбол без тёмного выступа под Бонго, «Привет!» с тремя пальчиками; отвергнутый вариант с двумя пальчиками не используется. Сцены комикса и провода берутся из согласованных версий.

## Сохранения

Ответы ребёнка Yes/No записываются сразу в localStorage отдельными ключами. Разные вкладки не должны стирать ответы друг друга. В You показано общее количество ответов и Yes/No. При всех No в грамоте остаются заголовок, имя, подписи и `You can speak English!`.

В настройках можно выбрать голоса, повторить обучалку и начать заново с очисткой прогресса. Разные браузеры и разные адреса имеют отдельные сохранения. Старый локальный файл и опубликованный сайт не переносят прогресс автоматически.

## Проверки перед публикацией

- Полное прохождение от знакомства до грамоты, 16 ответов про персонажей и 16 личных ответов.
- Доступность всех 58 ресурсов и декодирование 45 картинок.
- Сохранение имени и ответов после перезагрузки и действий в другой вкладке.
- Пять размеров экрана без прокрутки, мемори с пятью парами и победой, четыре подсказки для ребёнка.
- Проверки в отдельных тестовых профилях; реальные сохранения ученика не затрагиваются. Речь в автоматических тестах подменена; качество живого голоса ими не оценивается.

Не пересобирать игру старым `package-assets.mjs`: он относится к архивной структуре и может вернуть устаревшие рисунки. `tools/build-site.mjs` нужен только для контролируемого повторного преобразования архивного снимка, не для повседневного редактирования.
